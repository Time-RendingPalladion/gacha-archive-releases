# 抽卡档案馆发行版

本仓库只提供当前确认可用的 Windows / Android 正式版与自动更新元数据，不保存早期未完善版本。

- `Releases`：Windows 安装版、免安装版、blockmap 与 Android 正式 APK。
- `main/latest.yml`：Windows 自动更新回退元数据。
- `main/android-latest.json`：Android 更新回退元数据。
- 中国大陆网络优先读取腾讯云 COS 轻量清单；安装资源仍来自本仓库 Release。

源码维护于私有仓库 `Time-RendingPalladion/gacha-archive`。
